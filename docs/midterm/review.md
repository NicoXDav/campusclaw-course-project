## 实现边界

模型返回为用户授权的模拟 provider，真实网关未在线测试；MCP 为无状态 JSON 子集，只读工具白名单；技能为声明式 Markdown，未实现任意脚本/ZIP 资源执行。最多 4 轮工具调用、每轮 4 个工具，历史最多 12 条。生产多实例并发、分布式限流与长期数据保留策略需进一步设计。

## 安全与可维护性

功能放在独立 platform / platform_llm / platform_tools 模块。数据写入使用 SQLAlchemy，前端输出采用 textContent。私密凭证只从本地环境读取，Authorization 不写追踪；公开 JSON 证据仅使用课程样例。上线提交前再次扫描暂存文件，排除 .env、模型缓存、数据库与个人上传文件。

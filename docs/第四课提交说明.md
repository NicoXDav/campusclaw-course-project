# 第四次课：OpenSpec变更说明与开发仓库提交

## 本次变更

变更名称：`add-traceable-vector-retrieval`。在第三课登录、角色权限、班级隔离与材料入库的基础上，实现限定本班的知识库检索和内容溯源。

核心设计为：MySQL保存上传原文和切片，Qdrant保存真实语义向量及关联编号；支持关键字、向量和RRF混合检索；结果带材料标题、段号、字符范围及原文链接。查询班级来自服务端会话，不能通过请求参数跨班访问。无检索证据时直接返回无相关内容，不调用生成模型；配置生成网关后可根据本班证据形成带引用的简短回答。

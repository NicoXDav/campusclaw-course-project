## ADDED Requirements

### Requirement: 登录失败同形与限流
系统 MUST 对不存在账号、错误密码及限流返回相同401和文案，执行真实或dummy口令哈希验证并设置统一最低响应时间，不通过快速失败泄露账号存在性。单实例限流按可信代理提供的客户端IP，默认每分钟30次。

#### Scenario: 三种失败响应
- **WHEN** 分别请求不存在账号、错误密码或超过速率上限
- **THEN** 系统 MUST 返回同样401与用户名或密码错误，不签发会话，并在服务端记录失败类型而不记录口令

#### Scenario: 登录成功身份字段
- **WHEN** 合法用户登录且没有触发限流
- **THEN** 系统 MUST 返回用户id、用户名、角色及班级，不返回口令或哈希
